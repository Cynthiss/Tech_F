📖 Acerca del laboratorio

En este laboratorio se implementaron dos ejemplos de firmas criptográficas utilizando Node.js y la biblioteca Viem. El objetivo fue comprender cómo funcionan las firmas digitales utilizadas por Ethereum y cómo el estándar ERC-712 agrega contexto y seguridad al firmar datos estructurados.

🎯 Objetivos

ECDSA

Comprender cómo se generan claves criptográficas, cómo se firma un mensaje y cómo verificar su autenticidad.

Integridad

Demostrar que una firma alterada deja de ser válida inmediatamente.

ERC-712

Firmar datos estructurados utilizando dominios, tipos y mensajes siguiendo el estándar Ethereum.

Seguridad

Comprender el uso de los componentes r, s y v para la verificación mediante ecrecover.

🧪 Scripts desarrollados

Script 1 - Firmas ECDSA

  • Generación de claves secp256k1
  • Firma del mensaje "Hello UFM"
  • Verificación de firma
  • Firma corrupta
  • Generación de wallet Ethereum

Script 2 - ERC-712

  • Recuperación de wallet
  • Dominio EIP-712
  • Hash del mensaje
  • Firma tipificada
  • Extracción de r, s y v

📚 Conceptos aprendidos

🔑 Firmas Digitales

Permiten demostrar matemáticamente la autenticidad de un mensaje sin revelar la clave privada.

📝 ERC-712

Agrega contexto mediante dominios para evitar ataques de reutilización de firmas entre aplicaciones.

🌐 Ethereum

Utiliza ECDSA y el algoritmo secp256k1 para proteger transacciones y autenticar usuarios.

💡 Conclusión

Este laboratorio permitió comprender cómo funcionan las firmas criptográficas en Ethereum, desde la firma básica de mensajes hasta el estándar ERC-712 para datos estructurados. También mostró cómo la criptografía reemplaza la confianza en terceros mediante pruebas matemáticas, garantizando autenticidad, integridad y seguridad en aplicaciones blockchain.
